# HTTP Server

Multi-threaded HTTP server for static content hosting.

## Build

```bash
g++ -std=c++11 -pthread server.cpp -o server
```

## Run

```bash

```

Server runs on `http://localhost:8080`

## Pages

- `http://localhost:8080` - index.html
- `http://localhost:8080/page2.html` - page2.html
